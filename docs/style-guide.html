This post collects the visual elements of the Yaru theme and the options you can change in the Ghost admin. Use it as a reference when writing: everything here comes out of Ghost's standard editor, with no special HTML.

Palette

The theme follows Ubuntu 24.04's Yaru dark: charcoal surfaces, light text and the Ubuntu orange only in the details (cursor, active tab, links, buttons and focus).

The orange comes from Ghost's Accent color (Design & branding → Brand). Recommended: #E95420.

Typography

Text is set in Ubuntu Sans; code, metadata and prompts in Ubuntu Sans Mono. Both fonts ship with the theme. If you pick another font in Design & branding → Typography, it replaces Ubuntu Sans.

Code

With code_blocks_as_windows on, every code block becomes a GNOME window. The window title is the language picked in the editor's code card.

With syntax_highlighting on, code gets the Ubuntu terminal colors: keywords, strings, numbers, functions, tags and properties, variables, and comments in grey. It works with JavaScript, TypeScript, JSX, HTML, CSS, SCSS, Handlebars, JSON, YAML, Markdown, Bash, Dockerfile, Nginx, INI, TOML, diff, SQL, GraphQL, Python, Ruby, ERB, PHP, Go, Rust, Java, Kotlin, C, C++, C#, Swift, Lua and Elixir.

Theme options

All of them live in Settings → Design & branding → Customize, split across the panel's tabs.

Site-wide

  • terminal_prompt — user@host of the terminal prompt (home, breadcrumb, tag, author, 404). Empty = just ~$. Default: guest@localhost.
  • projects_tag — Slug of the portfolio tag. Its posts are left out of /blog/ and it doesn't show up in the category pills. Default: projects.
  • prompt_search — Title search in the prompt on the home, tag and author pages: type after the $ and the list is filtered. / focuses the search, Enter opens the first result and Esc clears it. Default: on.
  • show_blinking_cursor — Blinking orange cursor in the search prompt. Default: on.
  • signup_heading — Heading of the newsletter block (end of posts and footer). Default: site title.
  • signup_subheading — Text of the newsletter block. Default: site description.
  • github_url — Link to your GitHub profile. The icon shows up in the footer, after the social accounts set in Ghost. Default: empty.

Homepage

  • show_home_intro — Large intro sentence at the top of the home page. Default: on.
  • home_intro_text — The intro sentence (only shown with the option above on). Default: site description.
  • show_post_numbers — 01, 02… numbering in the post list. Default: on.
  • show_author — "BY AUTHOR" in the list metadata. Default: on.
  • show_reading_time — Reading time in the list. Default: on.
  • show_publish_date — Publish date in the list. Default: off.

Post

  • show_breadcrumb — Prompt-style breadcrumb (~/tag$) at the top of posts and pages. Default: on.
  • code_blocks_as_windows — Code blocks as GNOME windows, like the ones in the Code section. Default: on.
  • code_style — Colors inside the code window: Yaru (Ubuntu terminal colors) or Ray.so (the same GNOME window, with a purple background, semibold text and pink, yellow, green and cyan colors). Default: Yaru.
  • syntax_highlighting — Syntax colors in code blocks. Default: on.
  • show_post_signup — Newsletter block at the end of posts. Default: on.
  • show_related_articles — "Read next": three numbered posts that share tags with the current one. Default: on.

Recommended Ghost setup

  • Accent color: #E95420.
  • Primary navigation: a few short items, such as Home, Blog, Projects and About. Categories live in the pills on the Blog and tag pages. The current page gets the orange bar; items that don't fit go into the ⋮ menu.
  • Secondary navigation: footer links (e.g. About, RSS, Subscribe → #/portal/signup).
  • Social accounts (Settings → General): filled-in accounts show up as icons in the footer. GitHub comes from the theme's github_url option.
  • Logo: optional. Without one, the title is set in mono, exactly as written in Ghost.
  • Language: Settings → General → Publication language. The theme ships with English and Brazilian Portuguese.
  • Tags: the primary tag shows up in the metadata and the breadcrumb; "Read next" uses shared tags.
  • Members: with members enabled, Sign in/Subscribe show up in the header along with the newsletter block.
